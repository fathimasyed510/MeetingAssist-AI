# MeetingAssist AI

### An Intelligent Meeting Assistant Powered by Persistent AI Memory

## Problem
Important information from meetings often gets lost. Teams struggle to remember previous discussions, decisions, commitments and pending tasks.

## Our Solution
MeetingAssist AI transforms meeting recordings and text into useful information and preserves meeting context using Hindsight memory.

## Key Features
- Audio, video and text input.
- AI-powered meeting transcription.
- Automatic meeting summaries.
- Key discussion points and decisions.
- Action-item identification and tracking.
- Persistent meeting memory using Hindsight.
- Recall of previous meeting information.
- Ask Your Meetings for context-aware answers.
- Meeting history and report generation.

## Technology Stack
- Python
- Streamlit
- Groq API
- Whisper
- Hindsight
- ReportLab

## Hindsight Integration
MeetingAssist uses Hindsight to retain information from previous meetings, recall relevant context and reflect on accumulated meeting memories.

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure your API keys in `.env`.
5. Run the application using `python -m streamlit run app.py`.
